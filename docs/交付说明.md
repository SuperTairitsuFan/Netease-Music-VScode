## 0.2.3 修复：随包原生组件没有被发现

0.2.0 的 `ComponentStore.scan()` 把 `components/<platform>-<arch>/` 当成“每个子目录一个组件”，但实际打包布局是平铺的：

```
components/win32-x64/component.json
components/win32-x64/native-audio-output.exe
```

因此安装后设置页会显示「未安装 Native Audio Output Engine」，即使文件就在扩展目录里。0.2.3 已支持平铺清单，并在启动时自动把随包引擎启用；不需要再单独下载。

如果升级 0.2.3 后仍显示未安装：

1. 确认安装的是 **Windows x64** 包，而不是 Linux 包；
2. 彻底卸载旧版并重新安装 0.2.3；
3. 或在设置 → 组件点「安装组件」，选择包含 `component.json` 的 `components/win32-x64` 目录；
4. 之前手动「卸载」过随包组件时，记录会保留在 globalState 中，重装后仍可能被跳过；此时用「安装组件」重新安装一次即可恢复。

## 安装

```bash
code --install-extension dist-vsix/netease-music-0.2.3-win32-x64.vsix
```

或在 VS Code 扩展面板选择「从 VSIX 安装」。安装后点击 Activity Bar 的音乐图标；首次打开会加载推荐内容。

## 首次使用建议

1. 点击侧边栏「未登录」→ 扫码登录（推荐）或手机验证码。
2. 打开设置 → 音质与下载，确认播放音质；SVIP 账号可选择高清臻音 / 沉浸环绕声 / 超清母带。
3. 打开设置 → 系统，选择输出模式；安装原生引擎后可「探测」设备并选择 USB DAC，开启独占。
4. 打开任意歌单，确认歌曲/评论/收藏者标签、音质标签、右键菜单。
5. 试听时观察状态栏：歌名跑马灯、实际音质、音量；关闭主界面确认继续播放。
