# 需求对照表（0.2.3 · EAPI + PC 风 UI）

对应《VS Code 网易云音乐插件 —— 开发需求说明书（UI 与核心技术修订版）》。

## 一、核心底层架构：彻底脱离 Web 版

| 需求 | 落地位置 | 状态 |
| --- | --- | --- |
| 内置 EAPI 加密实现（AES/RSA） | `src/api/crypto.ts`、`src/api/http.ts` | 完成 |
| 模拟桌面客户端请求头 / 加密参数 | `EapiTransport`：`os/appver/osver/channel/deviceId/versioncode` + `header` 对象 | 完成 |
| 只走 EAPI，不加载网页端 | 所有客户端方法经 `EapiTransport.post`；无首页 bootstrap、无 Web 播放器 | 完成 |
| SVIP 音质 `sky` / `jymaster` | `NeteaseClient.songUrl` 直接请求 `level=sky/jymaster`；配置 7 档 | 完成（实际档位以账号权益为准） |
| 登录（验证码 / 密码 / 扫码）全部后台完成 | `src/auth/session.ts`、`src/api/client.ts`、设置面板登录弹窗 | 完成 |
| 歌单 / 搜索 / 歌词 / 评论 / 播放链接后台获取 | `src/api/client.ts` 各端点 | 完成 |
| 原生音频输出引擎（WASAPI / ALSA） | `native/`、`src/player/nativeEngine.ts` | 完成 |
| USB 独占 / 绕过系统混音 | `output.exclusive`、WASAPI Exclusive、ALSA `hw:` 直连 | 完成（需实机验证） |
| Bit-perfect / 源采样率透传 | 引擎输入 f32le，按源采样率配置；不做重采样 | 完成 |
| 探测 USB DAC 采样率 / 位深 | `--probe`、设置 → 系统「探测」；实际格式回显 | 完成 |
| 组件化：启用 / 禁用 / 卸载 / 自定义目录 | `src/player/components.ts`、设置 → 组件 | 完成 |
