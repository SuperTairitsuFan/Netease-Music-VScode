## 3. EAPI

### 3.1 请求

```
POST https://interface.music.163.com/eapi/<path>
Content-Type: application/x-www-form-urlencoded
params=<AES-128-ECB(e82ckenh8dichen8) 大写 hex>
```

签名负载：

```
<path>-36cd479b6b5-<json>-36cd479b6b5-<md5("nobody"+path+"use"+json+"md5forencrypt")>
```

`path` 必须是 `/api/...`；HTTP 端点才替换为 `/eapi/...`。

### 3.2 请求头 / Cookie

- `User-Agent`：桌面 Chromium UA，可配置。
- Cookie：`os=pc`、`appver=3.1.17.204416`、`osver`、`channel=netease`、`deviceId`、`versioncode=140`、`MUSIC_U`/`MUSIC_A`。
- 请求体 `header` 对象包含同一组指纹 + `requestId`。
- 只发 `os=pc` 会触发 `-462`；要么完整指纹，要么不发。

### 3.3 响应

- 普通 JSON。
- `#14` 前缀：AES-128-ECB 解密后 JSON。
- 拼接的两个 JSON：`parseLooseJson` 取第一个。
- 风控 code 406 / -462 / -460：等待 8s 重试一次。

## 4. 页面与播放链路

### 4.1 页面

```
sidebar 点击 → App 拉取 EAPI → MainPanel.post(page) → main.ts 渲染
```

页面类型：`recommend / featured / podcast / roam / following / playlist / album / artist / search / queue / downloads / recent / collections / local / cloud / now`。

### 4.2 播放

```
PlayerService.resolveUrl
  → /api/song/enhance/player/url/v1 (level)
  → 原生：下载缓存 → sidebar fetch 本地 URI → OfflineAudioContext(源采样率) 解码
        → nativeBegin → 引擎 → PCM 帧 → nativePcmAck → pcmDone → drained → 下一首
  → WebAudio：remote URL → sidebar 隐藏 <audio>
```

- CDN 无 CORS：原生路径必须宿主下载到本地；WebAudio 用 `<audio>` 不要设 `crossOrigin`。
- WebAudio 宿主在侧边栏，关闭主界面不中断。
- 原生引擎输入永远 f32le；`bits/sampleFormat` 描述设备输出格式。
- 引擎不做重采样；手动采样率必须等于音源。

## 5. 音质

| 档位 | 标签 | 权益 |
| --- | --- | --- |
| standard | 标准 | 免费 |
| exhigh | 极高 | VIP |
| lossless | 无损 | VIP |
| hires | 高解析度无损 | VIP |
| jyeffect | 高清臻音 | SVIP |
| sky | 沉浸环绕声 | SVIP |
| jymaster | 超清母带 | SVIP |

- 音质只决定源文件；实际档位由服务端返回 `level`。
- 播放 URL 约 20 分钟有效，按 `expi` 提前刷新。
- 歌单歌曲的 `maxBrLevel` 通过 `/api/song/enhance/privilege` 补齐，用于行内音质标签。

## 6. 组件模型

- store：`components.dir` 或 `<globalStorage>/components`；随包：`<extension>/components/<platform>-<arch>`。
- 清单：`component.json`（id、version、kind、platform、arch、entry、sha256、backend、protocol、formats）。
- 内置虚拟组件：`core.ui / core.account / core.player / core.downloader / core.manager`。
- 原生引擎可 `components.nativeEnginePath` 重定位；哈希不符标记 invalid。
- 缺失自动恢复：ready → 随包禁用则启用 → 否则按 `components.downloadUrl` 下载 zip → 校验 → 安装。
- 第三方 UI 仅支持清单、安装、启停、卸载，不执行未签名代码。
