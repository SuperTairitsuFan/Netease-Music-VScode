# 使用说明（0.2.3）

## 安装

1. 从 `dist-vsix/` 取得对应平台的 `.vsix`：
   - Windows x64：`netease-music-0.2.3-win32-x64.vsix`
   - Linux x64：`netease-music-0.2.3-linux-x64.vsix`
   - Linux arm64：`netease-music-0.2.3-linux-arm64.vsix`
2. VS Code → 扩展 → `···` → 从 VSIX 安装。
3. 安装后 Activity Bar 出现音乐图标；首次打开会加载推荐内容。

命令行安装：

```bash
code --install-extension dist-vsix/netease-music-0.2.3-win32-x64.vsix
```

## 界面

### 左侧侧边栏

| 区域 | 内容 |
| --- | --- |
| 顶部 | 搜索框、设置、刷新 |
| 账号 | 头像、昵称、VIP / SVIP 标识；点击打开设置 → 账号 |
| 导航 | 推荐、精选、播客、漫游、关注 |
| 我的音乐 | 我喜欢的音乐（醒目）、最近播放、我的收藏、下载管理、本地音乐、我的音乐网盘 |
| 歌单 | 创建的歌单、收藏的歌单，分组可展开/收起 |
| 底部 | 设置、组件、登录/登出、打开主界面 |
| 正在播放 | 小封面、歌名、上一首/播放/下一首、进度条；点击打开「正在播放」页 |

### 右侧主界面

- **推荐**：每日推荐、推荐歌单、排行榜、最新音乐、播客推荐。
- **精选**：排行榜 + 精选歌单。
- **播客**：推荐播客列表。
- **漫游**：随机漫游歌曲，可播放全部。
- **关注**：登录后显示关注的歌手。
- **歌单详情**：封面、创建者、创建时间、播放量、描述、标签、播放全部、加入队列、下载、更多、歌曲 / 评论 / 收藏者标签。
- **歌曲表格**：左侧序号 + 封面缩略图，歌名 + 音质标签，歌手，专辑，时长，红心，更多。
- **右键菜单**：播放、下一首播放、复制歌曲名、复制歌手名、查看专辑、查看歌手、下载。
- **专辑 / 歌手**：封面/头像、信息、热门歌曲。
- **搜索**：歌曲 / 歌单两种结果。
- **队列 / 下载 / 最近播放 / 我的收藏 / 本地音乐 / 音乐网盘**。
- **正在播放**：大封面、歌词、播放控制、进度、喜欢、下载、队列。

### 状态栏

状态栏右侧常驻：上一首、播放/暂停、下一首、歌名跑马灯、实际音质、音量。

- 点击歌名 → 打开正在播放页。
- 点击音质 → 7 档音质快速选择。
- 点击音量 → 0/20/40/60/80/100% 选择。
- 主界面关闭后，原生引擎继续播放；WebAudio 由持久侧边栏承载。

## 登录

侧边栏「未登录」或设置 → 账号：

- **扫码**：使用网易云音乐 App 扫码；支持 800 过期、801 等待、802 已扫码、803 成功。
- **手机验证码**：手机号 → 发送验证码 → 登录。
- **手机密码**：手机号 + 密码。
- **邮箱**：邮箱 + 密码。

登录态保存在 VS Code SecretStorage；退出登录会清除 Cookie。

## 音质

- 播放音质：设置 → 音质与下载 → 音质播放设置，或状态栏音质按钮。
- 下载音质：跟随播放音质，或固定档位。
- 七档：标准、极高、无损、高解析度无损、高清臻音（SVIP）、沉浸环绕声（SVIP）、超清母带（SVIP）。
- 服务端可能按版权 / 会员权益降级；状态栏与正在播放页显示**实际**档位。

## 原生音频输出

设置 → 系统：

1. 输出模式：自动 / 仅 WebAudio / 仅原生。
2. 点击「探测」调用引擎 `--probe`，列出设备与支持格式。
3. 点击「选择设备」写入 `output.device`。
4. 独占模式：WASAPI Exclusive / ALSA `hw:` 直连。
5. 采样率 / 位深 / 样本格式：`auto` 或固定值；引擎不做重采样，手动采样率必须等于音源。
6. 缓冲区：3–500 ms。

没有原生引擎时会自动回退 WebAudio（`output.mode=auto`）；设为 `native` 时失败直接报错，不静默回退。

## 下载

- 下载目录：设置 → 音质与下载，或 `neteaseMusic.download.dir`。
- 文件名模板、并发、ID3、歌词保存均可配置。
- 下载管理页显示进度，可取消、清理、打开目录。

## 本地音乐

设置 → 音质与下载 → 本地音乐目录；留空时扫描下载目录。支持 mp3 / flac / m4a / wav / ogg / ape。本地音乐通过 WebAudio 宿主播放。

## 组件

设置 → 组件：

- **内置模块**：核心 UI、登录与账户、播放器、下载器、组件管理器；可禁用，不可卸载。
- **原生组件**：Native Audio Output Engine；可启用/禁用/校验/重新定位/卸载。
- **第三方 UI**：安装包含 `component.json` 的组件目录。

组件目录默认 `<globalStorage>/components/`，可用 `neteaseMusic.components.dir` 修改。

## 设置与配置

命令面板「网易云音乐: 打开设置（客户端风格）」或「打开 settings.json（全部参数）」。

主要配置分组：

- `neteaseMusic.quality` / `download.quality`
- `neteaseMusic.download.*` / `cache.*` / `localMusic.dir`
- `neteaseMusic.output.*`
- `neteaseMusic.playback.*`
- `neteaseMusic.ui.*`
- `neteaseMusic.components.*`
- `neteaseMusic.api.*`（EAPI 基地址、超时、UA、realIP、额外 Cookie）

## 故障排查

| 现象 | 处理 |
| --- | --- |
| 没有声音，状态显示 WebAudio | 检查系统输出设备；打开日志看是否有原生引擎回退原因 |
| 原生输出报格式不支持 | 设置 → 系统「探测」，按列出的格式选择；或采样率设为 auto |
| 原生引擎未安装或未启用 | 设置 → 组件启用；检查 `.vsix` 是否对应平台 |
| 手动采样率报「与音源不一致」 | 引擎不做重采样，改为 auto |
| 登录失败 / -460 | 等待几十秒；避免短时间重复登录 |
| 搜索 / 推荐失败 | 检查网络与代理；日志会记录状态码 |
| 下载 403 | 签名 URL 过期，重新点击下载 |

日志：命令面板「网易云音乐: 显示日志」。

## 隐私

- 账号 Cookie 仅保存在本机 VS Code SecretStorage。
- 只向网易云音乐官方 EAPI 接口发送数据。
- 原生引擎只接收 PCM 并输出到本机音频设备，不联网。
